auteur

Point it at a pile of unsorted clips, give it a sentence of direction, and it returns a finished, graded, beat-cut, sound-designed short film — from the command line, or from your phone.

View the code Documentation

Run it

git clone https://github.com/abucaria-afk/Social-media.git
cd Social-media
pip install -r requirements.txt

python -m auteur demo      # makes practice clips, then edits them
python -m auteur serve     # then open the printed address on your phone

demo needs no footage, no arguments and no API key. serve puts the same agent behind a mobile web app you can add to the iPhone home screen, or install from Chrome.

There is no hosted version. The app decodes and re-encodes video, so it needs a machine with ffmpeg and CPU to spare — this page is static and cannot run it. It is meant to run on your own computer, with your phone reaching it over the same wifi.

What it actually does

It measures every clip frame by frame — motion, camera move, focus, exposure, colour, subject position — derives a beat grid from the music, cuts to it, grades and matches the shots, mixes the sound, and then watches its own output back and re-cuts what it got wrong. Claude directs when an API key is present; a full algorithmic director takes over when there is not one, so the film always gets made.

  • Cuts land on the beat, from a tempo and phase it works out itself
  • Reframes horizontal footage to vertical by following the subject
  • Speed ramps, invented camera moves, film grades, titles, sound design
  • Delivers several aspect ratios from one edit
  • Writes production notes explaining what it decided and why

How it was built

145 tests, plus a fuzz campaign of ten thousand randomised cases checking properties rather than examples. Everything either found has a named test. The palette on this page is generated from the same module the app, the icons and the terminal read, and a test asserts every text/background pair clears WCAG AA in both light and dark.
